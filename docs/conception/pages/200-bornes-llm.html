2.3 bis⏱️ Budget de temps : quatre LLM dans 8 secondes · ② les bornes

Les bornes LLM s'ajoutent aux bornes de 2.3 ; l'orchestrateur calcule le budget de chaque agent avant de l'appeler, l'agent le rogne encore du temps de sa référence.

Borne (provisoire)ValeurRôle
tours_max par agent3 · 2 · 3 · 2tours LLM ⇄ outils (1.4 ter) ; au-delà ToursEpuises ⇒ repli
delai_agent_s par agent1,2 · 0,8 · 1,5 · 1,2pieces · estimation · antifraude · decision : temps LLM de toute la boucle
delai_min_llm_s0,3en dessous : repli direct (cause budget), 0 appel LLM
reserve_decision_s1,0toujours gardé pour ⚖️ decision

jetons_max par agent3 000 · 1 500
4 000 · 3 000		max_tokens de chaque appel (sortie), pas un cumul
taux_repli_disjoncteur0,5plus de 50 % de replis ⇒ repli pour tous

Valeurs par agent : .env.example (KALDERA_<AGENT>__DELAI_AGENT_S, __JETONS_MAX, __TOURS_MAX) ; les autres : Bornes (etat.py), exposées par bornes(). L'agent de relance (2.8) a ses propres bornes (2,0 s, 600 jetons, 2 tours), hors des 8 s.

🔌 Le disjoncteur LLM (disjoncteur.py)

  • Un par orchestrateur, partagé par ses 4 agents ; traiter_demande en crée un à chaque appel : il ne s'ouvre donc que dans traiter_lot et le worker (un pour toute sa vie).
  • Ouvert ⇒ cause disjoncteur, aucun appel, rien de noté ; il se referme seul quand les tentatives sortent de la fenêtre.
  • Seules les tentatives LLM réelles sont notées. Panne : 10 appels, puis 0 (test_llm_en_panne_ouvre_le_disjoncteur_pour_tous).

📐 Budget dégressif (calculé par l'orchestrateur)

# Orchestrateur._budget
budget_s = max(0, duree_max_s − écoulé − réserves)
réserves = delai_partenaire_s   # 3 s : pieces, estimation (A2A pas encore passé)
         + reserve_decision_s   # 1 s : tout état sauf decision

# AgentLLM.executer, après la référence (dont l'A2A)
budget = min(delai_agent_s, budget_s − temps de la référence)
if budget < delai_min_llm_s: repli   # cause budget

⚖️ decision : min(delai_agent_s, duree_max_s − écoulé), sans réserve.

🧭 Ordre des contrôles dans executer

  1. référence déterministe (repli et étalon du garde-fou)
  2. LLM absent ⇒ repli, cause llm_non_configure
  3. disjoncteur ouvert ⇒ repli, cause disjoncteur
  4. budget < delai_min_llm_s ⇒ repli, cause budget
  5. tentative (boucle d'outils), puis disjoncteur.noter(repli=…)
Le temps des outils ne consomme pas delai_agent_s : la référence (A2A compris, borné à 3 s) passe avant, et seul le temps restant de la demande en est réduit. Chaque agent a son modèle et donc son délai (1.4 ter) ; température 0 ; la sortie est un objet JSON validé par le modèle de la section, puis par le garde-fou.
