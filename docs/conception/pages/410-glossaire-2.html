Annexe

A📖 Glossaire 2/5

Suite des termes, dans l'ordre alphabétique (de G à W).

TermeDéfinition
GardeCondition booléenne qui autorise une transition (≈ PermitIf de Stateless).
Générateur + validateurUn LLM produit, un contrôle déterministe valide, sinon repli ; un rejet ne relance jamais la génération, donc pas de boucle.
Indicateurs F1–F4Signaux de risque qui rendent l'avis anti-fraude obligatoire (§7).
JSON-RPCFormat d'appel distant (méthode + paramètres + id) utilisé par A2A.
Liste blancheSeuls les champs explicitement autorisés sortent ; tout le reste est bloqué (projection A2A, vue de l'assuré).
Machine à états finisEnsemble fini d'états reliés par des transitions gardées ; pattern retenu pour l'orchestration.
Mode dégradéPlan B métier quand le partenaire est indisponible (§9).
PatchModification proposée par un agent, limitée à sa section, contrôlée avant fusion.
Ping-pongDeux agents se renvoient la même tâche sans progresser.
ReaperProcessus indépendant (make reaper) qui repère les dossiers restés « en cours » trop longtemps (KALDERA_REAPER_AGE_S) et les escalade ; il a besoin de la base.
SnapshotCopie de l'état partagé enregistrée après chaque transition (table demandes, jsonb), pour reprendre un dossier après un crash ; seulement si une base est configurée.
SSEServer-Sent Events : réponse HTTP laissée ouverte où le serveur pousse des événements ; utilisé par le flux de l'espace assuré (5/5), pas avec le partenaire.
Table de transitionsListe (état, garde, suivant) : seule source de vérité du flux, évaluée dans l'ordre.
Tool déterministeFonction de code pure appelée directement (ex. is_eligible()) : pas d'agent, pas de LLM.
TransitionPassage d'un état à un autre, déclenché quand sa garde est vraie (≈ Fire de Stateless).
WatchdogSurveillant déterministe qui impose l'arrêt quand une borne est atteinte ; ici, la garde globale TG.
