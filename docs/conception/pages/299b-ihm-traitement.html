2.10📡 IHM gestionnaire · traitement, temps réel et suivi de lot (E3)

Le gestionnaire sélectionne des dossiers prêts et lance leur traitement (1 ⇒ E2, N ⇒ E3). L'avancement arrive en direct, jusqu'aux sous-étapes d'agent ; l'IHM n'interprète rien (EX-D44, EX-D45, EX-D46).

% agent / dossier / lot

Prévues = tours_max + 3 ; vue = 1, tour / outil k = 1 + k, garde_fou = tours_max + 2, fin d'étape = 100 % ; arrondi entier. Dossier : étapes faites / 5. Lot : dossiers clos / dossiers.

Robustesse

Signaux best effort, jamais bloquants (EX-01) : un échec d'émission est journalisé, l'événement perdu. Relecture de l'état à l'ouverture et à la reconnexion (« Reconnexion… »). Reaper si l'API meurt en cours de lot.
