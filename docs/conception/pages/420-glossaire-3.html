A📖 Glossaire 3/5

Les termes liés aux agents LLM.

TermeDéfinition
Agent LLMProgramme dont un LLM choisit les actions (appels d'outils) pour atteindre un but, dans des limites fixées par le code.
Azure AI Foundry · ChatCompletionsClientSeul fournisseur réel des modèles, appelé par le client ChatCompletionsClient du paquet azure-ai-inference ; AZURE_AI_CHAT_ENDPOINT et AZURE_AI_CHAT_KEY sont partagés par les agents et le VLM.
Boucle ReActRaisonner → agir (appeler un outil) → observer le résultat, jusqu'à une réponse finale ; ici ≤ tours_max tours (2 ou 3) et ≤ 4 appels d'outil.
Appel d'outil (tool calling)Le LLM demande l'exécution d'une fonction décrite par un schéma ; le code l'exécute (ou la refuse).
Allowlist d'outilsListe fermée des outils qu'un agent peut appeler ; tout autre appel lève OutilRefuse : repli tracé.
Sortie structuréeRéponse finale du LLM au format JSON, validée par le modèle Pydantic de la section (le patch).
Référence déterministePatch calculé sans LLM avant tout appel (_reference) : étalon des champs décisifs et repli ; pour antifraude, elle appelle le partenaire.
Garde-fou de sortieverifier_sortie : champs décisifs = référence, aucune donnée sensible, contrôle du texte (ex. plafond cité) ; violation ⇒ repli.
Repli déterministeChemin sans LLM : la référence elle-même ; pris si LLM non configuré, disjoncteur ouvert, budget insuffisant, erreur, sortie invalide, outil refusé, tours épuisés ou garde-fou violé (≈ fallback Polly).
Budget dégressifTemps LLM accordé à un agent : min(délai agent, temps restant − réserves aval).
Profil de modèleFamille de modèle choisie pour un rôle (multimodal pour le VLM : vision=true) ; le nom exact est une configuration (KALDERA_<AGENT>__MODELE).
Fabrique de LLMfabrique_llm(cfg, nom) : le ClientLLM Azure d'un agent depuis sa ConfigLLM (dans ConfigAgents) ; None ⇒ repli llm_non_configure.
ClientLLM (port)Interface synchrone completer(systeme, messages, outils, timeout_s) ; implémentations AzureLLM et FakeLLM (≈ ILlmClient).
FakeLLMFaux LLM scripté pour les tests : rejoue des appels d'outils ou simule 7 défauts (menteur, bavard, lent, cassé, intrus, fuite, injecté).
Injection de promptTexte non fiable qui tente de se faire passer pour une instruction ; neutralisé par balisage (<donnees_non_fiables>), outils gardés et garde-fou.
Prompt système versionnéConsigne de rôle et de frontière d'un agent, stockée comme du code (prompts/<agent>.md) ; son empreinte version_prompt est tracée.
Disjoncteur LLM> 50 % de replis parmi les tentatives LLM des 60 dernières s (10 au moins) ⇒ repli des 4 agents sans appel (disjoncteur) ; se referme seul.
Jeton (token)Unité de texte comptée par le LLM ; la sortie d'un appel est bornée par jetons_max (max_tokens).
