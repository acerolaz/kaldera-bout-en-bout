2.9🔎 IHM gestionnaire · lecture des dossiers (E1, E2)

Le gestionnaire lit les dossiers traités par l'équipe d'agents. L'IHM n'interprète rien (EX-D44) : une projection serveur (vue_gestionnaire.py) transforme l'état en base en vues typées, que l'écran affiche telles quelles.

Avancement

(termine + sautee + repli + degrade) / 5 × 100 ; statut terminal (terminee, secours) ⇒ 100 %. Écart assumé au brief « (termine + sautee) / 5 » : une étape finie en repli ou dégradé est faite, sinon la barre stagne. en_cours n'est jamais produit ici.

Liste blanche

La projection n'expose jamais l'email, le téléphone, l'IBAN, l'adresse, le code postal ni l'identifiant client ; un test vérifie le JSON sérialisé. Résumés d'étape formatés côté serveur (1 230 €).

API

GET /demandes : filtres combinés en ET, tri par référence décroissante. GET /demandes/{ref} renvoie DossierVue (404 si inconnue), qui garde reference, statut et fiche par compatibilité.
