2.3🛑 Bornes = gardes, terminaison prouvée

Les bornes sont fixées a priori, paramétrables (Bornes, etat.py), exposées par bornes(), éprouvées par make epreuve ; elles sont des gardes de la machine. L'ingestion a ses propres bornes, hors du budget de 10 s.

🔁 Le piège à boucle BCL-01

Facture illisible → nouveau dépôt → facture toujours illisible. Sans garde, T4 bouclerait. Avec garde : arret = {borne: "relances_pieces_max", …}, T5 vers decision, escalade gestionnaire.

⚠️ Vigilance : T4 relit les dépôts de l'espace assuré (port DepotPieces, outil lire_depot), elle n'attend pas un dépôt. Une vraie attente violerait les 10 s du §12 (pattern interrupt / resume, 2.1 bis).

🔒 Trois verrous de terminaison

  1. Graphe fermé, prouvé statiquement : tout état non terminal atteint un état terminal, T0 compris, sans rejouer un seul scénario.
  2. Escalade forcée : garde globale ou échec d'un agent ⇒ transition forcée vers decision ; l'issue reste écrite par son seul propriétaire (decision elle-même en échec ⇒ fiche de secours).
  3. Filet de sécurité si le système plante, reaper si le processus meurt (2.5).
def test_tout_etat_non_terminal_atteint_un_terminal() -> None:
    for etat in set(Etat) - TERMINAUX:
        assert peut_atteindre(etat, TERMINAUX), etat

def test_la_seule_boucle_est_la_relance_des_pieces() -> None:
    boucles = {(depart, suivant) for depart, _, suivant in TRANSITIONS
               if depart == suivant}
    assert boucles == {(Etat.PIECES, Etat.PIECES)}

def test_etat_terminal_sans_transition_leve_une_erreur() -> None:
    with pytest.raises(TransitionInconnue):
        transition(Etat.ACCEPTEE, _etat(), BORNES)

def test_t0_mene_a_decision() -> None:
    assert (Etat.ELIGIBILITE, Etat.DECISION) in {(d, s) for d, _, s in GARDES_ENTREE}

def test_is_eligible_non_appele_si_contrat_non_valide() -> None:
    espion = Espion()
    fiche = _orchestrateur(eligibilite=espion).traiter(_contrat("non_exploitable"))
    assert espion.appels == 0   # + escalade gestionnaire, trace T0 puis T11

💥 Erreurs observables · 🏁 états terminaux

  • ErreurEcriture · TransitionInconnue (et KeyError, ValueError…) → étape echec, echecs + 1, escalade forcée motivée.
  • Indisponible (avis A2A non obtenu) → étape antifraude echec, motif = cause, mode dégradé §9.
  • ErreurLLM · OutilRefuse · ToursEpuises → pas d'échec : repli, mode=repli, cause tracée.
