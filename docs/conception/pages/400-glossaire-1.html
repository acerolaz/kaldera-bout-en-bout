A📖 Glossaire 1/5

Les termes techniques utilisés dans ce dossier, dans l'ordre alphabétique (de A à F).

TermeDéfinition
A2AAgent-to-Agent : protocole pour qu'un agent délègue une tâche à un agent externe sans exposer sa logique.
Action d'étatTraitement exécuté quand la machine est dans un état : ici le tool ou un agent (≈ OnEntry de Stateless).
Agent CardFiche publiée par un agent A2A (/.well-known/agent.json) qui décrit ses compétences et son URL d'appel (≈ swagger.json) ; lue au démarrage, son URL n'est suivie que si elle a la même origine que la base, sinon /a2a.
Agent-as-toolSous-agent appelé comme un outil par l'orchestrateur ; il n'a pas de boîte de messages propre.
BorneLimite d'exécution (étapes, durée, relances) qui garantit l'arrêt ; portée par une garde.
Circuit breakerDisjoncteur qui cesse d'appeler un service en panne pendant un temps donné (≈ Polly CircuitBreaker) ; ici, le disjoncteur LLM (3/5).
Claim checkPattern où l'on transmet une référence vers un contenu stocké ailleurs, pas le contenu (≈ ticket de vestiaire).
Court-circuitSortie anticipée vers la décision dès qu'une règle conclut.
Couverture des transitionsPart des transitions T1–T11 empruntées par au moins un scénario de test ; mesurée par make epreuve.
DepotPiecesPort synchrone d'accès aux pièces d'une demande (initiales, depots), aux implémentations interchangeables : lecture dans la demande ou dans PostgreSQL (≈ IRepository injecté par DI).
EmpiètementUn agent fait le travail d'un autre : violation de frontière.
Escalade forcéeIssue d'escalade produite quand une borne ou une erreur interrompt le flux.
État (machine)Situation stable de la demande dans le flux : eligibilite, pieces… ; un seul état courant à la fois.
État terminalÉtat sans transition sortante : acceptee, refusee, escalade.
Exécution durablePattern qui persiste l'état après chaque pas pour reprendre ou escalader après un crash (Temporal, Durable Functions) ; ici snapshots + reaper, actifs dès qu'une base est configurée.
Filet de sécuritéMécanisme hors équipe d'agents qui produit une escalade humaine depuis le dernier état connu quand le système plante.
