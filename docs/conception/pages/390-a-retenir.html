6📌 À retenir

Les dix idées à garder en tête — et à savoir défendre devant le formateur et la promo.

🏁

Jamais de blocage silencieux

Tout état non terminal mène à ⚖️ decision, prouvé sur le graphe ; si le système plante, le filet escalade le dossier, et le reaper prend le relais avec la base.

🔧

Tool plutôt qu'agent

L'éligibilité est une fonction pure is_eligible() : 4 agents LLM dans la machine, 1 section = 1 écrivain. La relance de l'assuré est un 5ᵉ agent, hors machine.

💶

Point ambigu tranché

Le plafond est appliqué par 💶 estimation, après la franchise — prouvé par NOM-05.

🔀

Machine à états finis

Table de transitions + gardes, exécutée par un orchestrateur explicite, sans LLM ; agents-outils ⇒ 0 ping-pong.

🧠

Mémoire partagée

Un état Pydantic par demande ; chaque agent propose un patch de sa section ; etat_courant tracé.

⚖️

Le LLM rédige, la référence décide

Chaque agent calcule d'abord sa référence déterministe ; le garde-fou impose les mêmes champs décisifs, sinon repli. Même issue avec ou sans LLM.

🔐

A2A sans confiance aveugle

7 champs en sortie (contrat v2.0), validation 4 couches en entrée, 1 seul appel réservé avant l'envoi ; Agent Card suivie à même origine seulement.

📥

Lu une fois, au dépôt

Le VLM analyse chaque fichier hors des 10 s ; l'équipe ne lit que des descripteurs validés. Le contrat PDF fait foi sous trois verrous.

🛑

Bornes = gardes

12 étapes · 8 s · 1 relance · 3 s ; un disjoncteur coupe le LLM en panne pour les 4 agents.

📏

Mesurer pour de vrai

make epreuve : EX-01 → EX-06 et T1–T11 couvertes, référence archivée. make eval choisira le modèle de chaque rôle.

« Les agents proposent, l'orchestration impose. »

La table de transitions est la seule source de vérité du flux : chaque règle de la spec devient une garde ou un contrôle dans le code, et chaque agent LLM reste borné par sa référence déterministe. C'est ce qui rend les six exigences démontrables par les tests et par l'épreuve.
