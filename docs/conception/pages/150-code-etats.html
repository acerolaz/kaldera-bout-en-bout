🎯 Ce qu'il faut voir

  • Chaque ligne porte son numéro T0 → T11 : la relecture se fait avec la table 2.2 à côté.
  • Les gardes sont des fonctions pures : elles lisent l'état, ne le modifient jamais.
  • TG (garde globale) n'est pas dans la table : le moteur l'évalue avant chaque action (page suivante).
  • T0 vit dans une liste à part, GARDES_ENTREE : elle doit être évaluée avant l'action, pas après.
