1.4🤖 Un LLM par agent

Chaque agent métier a son LLM : il lit sa vue, appelle ses outils et rédige le texte de sa section. Tout ce qui décide (statut, montant, avis, issue) vient d'une référence déterministe calculée d'abord ; la sortie du LLM est vérifiée contre elle avant d'entrer dans l'état. L'orchestrateur ne voit qu'une boîte : vue → patch.

Ce qui ne change pas

Le contrat agent ↔ orchestrateur reste executer(vue, budget) → (patch, mesure) : machine à états, tests statiques, fusion et A2A sont intacts. Seul l'intérieur de la boîte change.

Principe directeur

« L'outil calcule, le LLM rédige, le code vérifie. » Une règle métier n'est jamais dans un prompt : elle est dans la référence déterministe, et le garde-fou refuse tout écart.
