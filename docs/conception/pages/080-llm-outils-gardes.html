1.4 bis🧩 Ce que fait le LLM de chaque agent · ① outils et garde-fous

Pour chaque agent : la part du LLM, ses outils exclusifs, son garde-fou de sortie et son repli. Les outils rendent la référence déterministe (« fait foi ») : le LLM ne peut changer ni un statut, ni un montant, ni un avis, ni une issue.

Agent🤖 Le LLM…🧰 Outils exclusifs (garde dans l'outil) 🛡️ Garde-fou de sortie (vérifié par le code)🛟 Repli
📄 piecesrapproche les pièces jointes des pièces attendues, lit le dépôt de la relance en cours, rédige le message de relance à l'assuré verifier_completude() · pieces_requises() · lister_pieces() · lire_depot(k) (garde : k = n° de la relance en cours) statut, manquantes, retenues = référence ; message présent si incomplet, absent sinon référence + gabarit de relance
💶 estimationrédige l'explication lisible (déclaré → justifié → franchise → plafond) calculer_estimation() · bareme() (franchise et plafond de la formule) tous les montants = référence ; l'explication cite franchise et plafond calcul + gabarit d'explication
🕵️ antifraudelit les indicateurs et l'avis (niveau, score), rédige une note de synthèse pour la cellule calculer_indicateurs() · consulter_partenaire() : renvoie l'avis déjà obtenu par la référence, refuse sans indicateur, jamais de second appel requis, indicateurs, statut = référence ; avis et cause privés (recopiés, jamais vus) ; note sans réponse brute indicateurs + appel A2A unique (registre) + gabarit
⚖️ decisionrédige le motif de la fiche appliquer_regles_s10() (issue, décision, montant, file) · gabarit_motif() issue, décision, montant et file = référence ; le motif cite la règle référence + motif type
Pour tous : aucune donnée sensible dans le texte (e-mail, IBAN, téléphone, nom ou prénom de l'assuré) ; toute violation ⇒ repli, tracé mode = repli, cause = garde_fou (gardes_fous.verifier_sortie).

⛔ Le LLM ne fait jamais

  • chiffrer, décider une issue ni décider d'appeler le partenaire
  • voir l'identité, l'IBAN, le numéro de contrat, la réponse brute du partenaire
  • appeler un autre agent ou un outil hors allowlist (≤ 4 appels)
  • écrire hors de sa section
  • lire un fichier brut : il ne voit que des descripteurs

💡 Pourquoi un LLM ici ?

  • Rédiger pour un humain : relance, explication, note, motif — sa vraie valeur ajoutée
  • S'appuyer sur des faits : ses outils lui donnent statut, barème, indicateurs et avis, jamais à deviner
  • Choix de sûreté assumé : l'issue reste identique avec ou sans LLM (invariance, mesurée par make eval) et le partenaire n'est appelé qu'une fois

🔭 Honnêteté de conception

Les quatre LLM sont « minces » : ils rédigent. 💶 estimation l'est le plus. Si make eval montre un taux de repli élevé ou aucune valeur ajoutée, l'agent redeviendra un tool — décision consignée au journal.
