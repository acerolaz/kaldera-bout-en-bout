3.3🧾 La requête et la réponse, en JSON

Exemples tirés du contrat v2.0 §2 et §3. Les pastilles renvoient aux contrôles faits par le client A2A (partenaire.valider_reponse).

POST URL de l'Agent Card · message/send · jeton Bearer
{
  "jsonrpc": "2.0",
  "id": "c0a8012e-4f1b-4c55-9d1e-2b7e1f0e6a10",  ◀ ①
  "method": "message/send",
  "params": {
    "message": {
      "role": "user",
      "messageId": "8d3f2a64-1c0e-4e2b-a7b5-0f6c9e1d2a33",
      "parts": [                                    ◀ ②
        { "kind": "data",
          "data": {
            "reference_dossier": "KAL-26-0042",     ◀ ③
            "type_sinistre": "degat_des_eaux",
            "montant_declare": 1850.0,
            "date_survenance": "2026-08-14",
            "anciennete_contrat_jours": 942,        ◀ ④
            "sinistres_12_mois": 0,
            "departement": "69"                     ◀ ④
          } } ] } } }
  • ① UUID unique par appel : la réponse doit porter le même id (couche ②).
  • ② Exactement une partie de type data.
  • ③ 7 champs, tous obligatoires, aucun autre (RequeteAntifraude, extra="forbid", strict).
  • ④ Champs calculés par Kaldera : ancienneté = survenance − souscription ; département dérivé du code postal.
200 Réponse : tâche terminée + artefact data
{
  "jsonrpc": "2.0",
  "id": "c0a8012e-4f1b-4c55-9d1e-2b7e1f0e6a10",  ◀ ①
  "result": {
    "kind": "task",
    "id": "tsk-5d0c1b9e",
    "status": { "state": "completed" },            ◀ ⑤
    "artifacts": [
      { "artifactId": "art-5d0c1b9e",
        "parts": [
          { "kind": "data",
            "data": {
              "reference_dossier": "KAL-26-0042",
              "score": 0.08,                        ◀ ⑥
              "niveau": "faible",                   ◀ ⑥
              "indicateurs": [],
              "evaluation_id": "EVA-3f9a1c2b7d",    ◀ ⑦
              "version_modele": "af-2.3.1"
            } } ] } ] } }
  • ⑤ result.kind = task, status.state = completed, un seul artefact, une seule partie data, sinon réponse écartée.
  • ⑥ Cohérence : faible si score < 0,40 · modere si < 0,75 · eleve sinon ; score dans [0, 1] ; même reference_dossier.
  • ⑦ evaluation_id et version_modele conservés pour l'audit ; 6 champs exactement (ReponseAntifraude).
