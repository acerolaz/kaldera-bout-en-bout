1.4 bis🧩 Ce que fait le LLM de chaque agent · ② la fabrique

Les 4 agents partagent un seul mécanisme, AgentLLM : seules leurs données changent. Chaque sortie de LLM passe un garde-fou avant d'entrer dans l'état. Extraits de src/kaldera/agents_llm.py.

# fabrique d'agents : 4 agents, 1 mécanisme, seules les données changent
@dataclass(frozen=True)
class SpecAgent:
    section: str                       # section écrite
    modele_section: type[BaseModel]    # Pieces, Estimation…
    champ: str                         # champ rédigé par le LLM
    gabarit: Callable[[dict], str | None]  # texte du repli
    outils: Callable[[Vue, dict], list[Outil]]
    controle: Controle                 # contrôle du texte
    fabrique_repli: Callable[[Bornes, Evaluateur | None], Repli]
    prives: tuple[str, ...] = ()       # jamais montrés au LLM

SPECS = MappingProxyType({
  "pieces":     SpecAgent("pieces", Pieces, "message_relance", …),
  "estimation": SpecAgent("estimation", Estimation, "explication", …),
  "antifraude": SpecAgent("avis_fraude", AvisFraude, "note", …,
                   prives=("avis", "cause")),
  "decision":   SpecAgent("issue", Issue, "motif", …)})

def creer_agent(nom, llm, config, bornes, evaluer=None,
                disjoncteur=None) -> AgentLLM:
    spec = SPECS[nom]
    return AgentLLM(nom, spec, spec.fabrique_repli(bornes, evaluer),
                    llm, config or ConfigLLM(modele="aucun"),
                    bornes, disjoncteur)
# AgentLLM.executer : la référence d'abord, le LLM ensuite
def executer(self, vue, budget_s):
    ref = self._reference(vue)        # repli déterministe (A2A compris)
    if self.llm is None:
        return repli(ref, cause="llm_non_configure")
    if self.disjoncteur.ouvert():
        return repli(ref, cause="disjoncteur")
    budget = min(delai_agent_s, budget_s - temps_de_la_reference)
    if budget < bornes.delai_min_llm_s:   # 0,3 s
        return repli(ref, cause="budget")
    patch = self._tenter(...)   # boucle d'outils puis garde-fou
    self.disjoncteur.noter(repli=patch is None)
    return patch or ref

# _tenter : chaque échec a sa cause, tracée dans la mesure
#   ErreurLLM       → erreur_llm      (délai, fournisseur)
#   ValueError      → sortie_invalide (JSON, modèle Pydantic)
#   OutilRefuse     → outil_refuse    (hors allowlist, > 4)
#   ToursEpuises    → tours_max
#   verifier_sortie → garde_fou       (écart à la référence)

Le second extrait est condensé (noms et ordre réels, écriture simplifiée) ; le premier reprend les signatures exactes.

🏭 Fabrique d'agents

Table SPECS + fonction creer_agent() : ajouter un agent = une ligne (OCP). Pas d'Abstract Factory ni de sous-classe. En test, FakeLLM passe par la même fabrique (DIP). L'agent de relance (2.8) réutilise le même AgentLLM.

🛡️ Garde-fou de sortie

Fonction pure verifier_sortie(patch, ref, vue, …) → violations, testée sans LLM : champs décisifs = référence, aucune donnée sensible, contrôle du texte propre à l'agent. Une violation ⇒ repli, tracé mode = repli + cause.

🧾 Prompt versionné

Le prompt système est un fichier, prompts/<agent>.md ; sa version (8 premiers caractères du sha256) part dans chaque étape de trace avec le modèle : une fiche dit toujours quel prompt l'a rédigée.
