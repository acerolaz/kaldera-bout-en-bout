Pourquoi « machine à états » ?

Un pipeline est une ligne droite. Notre flux a une boucle (relance des pièces) et des sorties anticipées : c'est un graphe d'états. Le glossaire du brief le prévoit : un workflow est « un pipeline ou une machine à états codée ».

Pourquoi pas un LLM superviseur ?

Le chemin est écrit dans la spec : un LLM ajouterait coût, latence et imprévisibilité. La table de transitions est la spec, en code (machine.py).
