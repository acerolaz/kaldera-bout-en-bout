A📖 Glossaire 5/5

Les termes liés à la liaison A2A, à la mesure (chantier 2) et à l'IHM gestionnaire (chantier 3).

TermeDéfinition
Registre A2ARéservation de l'appel unique d'un dossier avant l'envoi (table appels_partenaire, ou en mémoire sans base) : un doublon ne part jamais (EX-D19).
Nature d'un appel A2AClassement de chaque appel au partenaire : ok, timeout, invalide, erreur, non_envoye, non_requis ; seuls les quatre premiers comptent comme appels externes.
Épreuve (make epreuve)tools/epreuve.py rejoue les 28 scénarios contre le partenaire simulé, lancé dans le processus : verdict EX-01 → EX-06, couverture T1–T11, seuils d'équipe ; rapport md + json, code 1 si échec.
Eval (make eval)tools/eval_llm.py : passe de référence sans LLM, puis 5 répétitions par modèle ; matrice agent × modèle (replis > 20 %, sorties rejetées > 5 %, latence p95 > délai, tours > 2,5), recommandation par rôle, bornes remesurées. Sans clés : « non mesuré », code 2.
InvarianceMêmes champs décisifs (issue, décision, montant, file, mode dégradé) avec ou sans LLM ; éprouvée par tests/unit/test_invariance.py et par make eval.
Design systemRègles visuelles communes (couleurs, typographie, composants, états) du back-office, dans design-system/kaldera/ ; produit avec ui-ux-pro-max.
Token de designVariable CSS nommée (--primary, --ton-danger…) définie une fois par thème ; les écrans n'utilisent jamais une couleur en dur.
Thème clair / sombreJeu de tokens choisi par l'attribut data-theme ; défaut : thème du système ; choix mémorisé (kaldera.theme).
Projection (vue gestionnaire)Fonction pure du serveur qui transforme l'état d'une demande en vue affichable (LigneDemande, DossierVue) ; l'IHM n'interprète rien.
Statut d'affichageStatut d'une étape vu par le gestionnaire (en_attente, termine, sautee, echec, repli, degrade), déduit de la trace.
