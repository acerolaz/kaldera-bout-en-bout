A📖 Glossaire 5/5

Les termes liés à l'espace assuré, à la liaison A2A et à la mesure (chantier 2).

TermeDéfinition
Espace assuréFront React 19 / Vite / Tailwind / shadcn et API /assure/* : l'assuré dépose ses pièces, soumet son dossier, suit 5 étapes et lit un verdict expliqué.
Vue projetéeSeul passage de l'état interne vers l'assuré (vue_assure.py) : liste blanche, DTO extra="forbid" ; jamais l'avis anti-fraude, le score, les indicateurs, la file cellule_fraude ni le mode dégradé.
Flux SSEGET /assure/demandes/{reference}/flux : pousse les événements de evenements_assure (étape, pièce, message, verdict) publiés par le worker et le reaper ; reprise par Last-Event-ID.
Agent de relance5ᵉ agent LLM, hors machine à états (relance.py) : répond aux questions de l'assuré sur ses pièces ; outils liste_pieces et consigne_depot, 600 caractères au plus, TERMES_INTERDITS ⇒ repli sur gabarit.
argon2 / sessionMots de passe hachés par argon2 ; session = cookie signé (kaldera_session, clé KALDERA_SESSION_SECRET) valable 8 h ; compte bloqué 5 min après 5 échecs.
Registre A2ARéservation de l'appel unique d'un dossier avant l'envoi (table appels_partenaire, ou en mémoire sans base) : un doublon ne part jamais (EX-D19).
Nature d'un appel A2AClassement de chaque appel au partenaire : ok, timeout, invalide, erreur, non_envoye, non_requis ; seuls les quatre premiers comptent comme appels externes.
Épreuve (make epreuve)tools/epreuve.py rejoue les 28 scénarios contre le partenaire simulé, lancé dans le processus : verdict EX-01 → EX-06, couverture T1–T11, seuils d'équipe ; rapport md + json, code 1 si échec.
Eval (make eval)tools/eval_llm.py : passe de référence sans LLM, puis 5 répétitions par modèle ; matrice agent × modèle (replis > 20 %, sorties rejetées > 5 %, latence p95 > délai, tours > 2,5), recommandation par rôle, bornes remesurées. Sans clés : « non mesuré », code 2.
InvarianceMêmes champs décisifs (issue, décision, montant, file, mode dégradé) avec ou sans LLM ; éprouvée par tests/unit/test_invariance.py et par make eval.
