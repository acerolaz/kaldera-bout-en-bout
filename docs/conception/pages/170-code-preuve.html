def peut_atteindre(
    depart: Etat, cibles: set[Etat] | frozenset[Etat]
) -> bool:
    """Parcours en largeur de la table :
    existe-t-il un chemin de depart vers une cible ?"""
    vus, file = {depart}, [depart]
    while file:
        e = file.pop(0)
        if e in cibles:
            return True
        for d, _, s in TRANSITIONS + GARDES_ENTREE:  # T0 compris
            if d == e and s not in vus:
                vus.add(s)
                file.append(s)
    return False

⚖️ Différence notable : Stateless refuse deux gardes vraies en même temps, ce qui impose des gardes mutuellement exclusives. La table Python, elle, s'appuie sur l'ordre (la première garde vraie gagne), d'où TOUJOURS en dernière position. T0 y devient un état Admission intermédiaire, dont les deux gardes sont exclusives ; OnEntry(Eligibilite) n'est jamais déclenché sur un contrat non validé.
