🧭 Fil conducteur

Une demande traverse trois temps : les fichiers sont lus au dépôt par un VLM utilisé comme outil (2.4 ter) ; après soumission, le contrôle d'admission la fait entrer dans la machine à états (2.2) ; quatre agents LLM rédigent sur des données validées, chacun borné par sa référence déterministe, l'orchestrateur décide du chemin et ⚖️ decision conclut. Le contrat PDF fait foi sous trois verrous (2.4 quater) ; l'état est persisté dans PostgreSQL dès qu'une base est configurée (2.6). L'assuré suit son dossier dans son espace (2.8).

✔️ Les règles métier restent dans des outils déterministes : elles ont été vérifiées en rejouant les 34 demandes des 28 scénarios (make epreuve : toutes conformes à l'attendu, EX-01 à EX-06 vérifiées). Le LLM ne peut changer aucune issue : il consulte ses outils et rédige.
