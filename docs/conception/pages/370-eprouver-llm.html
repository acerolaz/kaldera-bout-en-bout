😈 Les 7 modes du FakeLLM saboteur

  • menteur : champ décisif faux → garde-fou ✗
  • bavard : appels d'outils sans fin → plafonné, repli
  • lent : dépasse le budget → erreur_llm
  • casse : JSON invalide → sortie_invalide
  • intrus : outil hors allowlist → outil_refuse
  • fuite : IBAN / e-mail dans le texte → garde-fou ✗
  • injecte : « ignore tes règles » dans la vue → issue inchangée

🎯 Critère d'invariance

Pour chacune des 34 demandes : issue, decision, montant_rembourse, file, mode_degrade identiques en mode fake et en repli — et chaque étape d'agent bien en mode llm. Le LLM améliore les textes ; il ne décide rien.

@pytest.mark.parametrize("demande", DEMANDES)
def test_meme_issue_en_fake_et_en_repli(demande):
    repli = Orchestrateur(evaluer=_avis).traiter(demande)
    fake = Orchestrateur(evaluer=_avis, llms=llms).traiter(demande)
    assert {k: fake[k] for k in DECISIFS} \
        == {k: repli[k] for k in DECISIFS}
